# 暖隅日记

本地生活日记系统：Flask + 原生 HTML/CSS/JavaScript + SQLite。无需 Node.js、前端构建步骤或本地大模型。

## 启动

首次安装：

```sh
cd /Users/pris/Desktop/暖绒日记
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

当前电脑已创建虚拟环境、安装依赖并配置 `.env`，可直接执行：

```sh
.venv/bin/python app.py
```

打开 <http://127.0.0.1:5050>。也可双击 `启动日记.command`。已运行时无需重复启动；停止服务按 Ctrl+C。

演示账号：`demo` / `diary2026`，含三篇虚构示例日记。注册自己的账号后数据相互隔离。`seed_demo.py` 可选创建演示数据，重复运行不会覆盖已有账号。

## 已实现

- 注册、登录、退出；用户名和密码注册，未登录先进入账号页面，密码哈希存储、会话认证和 CSRF 校验。
- 个人中心：本地头像上传、六种动物头像、昵称、主动填写性别、简体中文/英语切换，以及旧密码/新密码/确认新密码修改；更改密码后其他会话失效。
- 记账簿：收入/支出新增、编辑、删除；个人中心可保存人民币 RMB、港币 HKD、新台币 NTD、英镑 GBP、美元 USD 的交易货币。每笔账目保存自己的币种，日/月/年统计只计算当前币种，不作汇率换算；原有账目保留人民币。金额使用整数分，按用户隔离。
- 月度与年度收支默认折叠，点击显示收入、支出与结余；跟随所选日期的月份与年份。收起或离开记账簿会清除已显示的统计金额，下次进入重新展开查看。
- 日记新增、编辑、删除，日期、六种自选心情、最多五个标签。标题可选，留空时使用日期标题。
- “保存日记”保存后返回列表；“保存并复盘”先保存，再确认发送至 DeepSeek。取消或复盘失败不影响已保存正文，可重试。保存错误在编辑窗口中显示，手机端也保留保存状态。
- 全文关键词、日期范围、日历日期、心情、标签筛选，分页加载。
- 本周与近7/30天心情趋势，同一天取自选心情分值均值；无记录不补造数据。这不是心理测量量表。
- 单篇、时间段 DeepSeek 复盘：情绪词、温和解读、饮食与维生素科普、轻运动与观看关键词。
- 图文活动时间线：复盘同时生成3至5项建议，显示开始/结束时间、持续分钟与活动插画；起点可调整、后续自动顺延，跨午夜标注次日。旧复盘可通过“生成活动时间线”升级。
- 发送前确认，复盘缓存，编辑后失效；超时、欠费、密钥错误、格式异常均显示错误，不伪造结果。
- 奶油风响应式布局、本地水彩插画、轻微浮动动画与减少动态效果适配。

后续已加入本地轻音乐、语音引导和离线小游戏，见下文。

## 配置与数据

- `.env`：后端密钥与模型配置；已加入 `.gitignore`，权限为仅本机文件所有者可读写。不会返回浏览器。
- `.env.example`：不含密钥的配置模板。
- `instance/diary.sqlite3`：本地数据库；日记为 SQLite 普通文本存储，未做磁盘加密。
- `app.py`：后端和建表逻辑；`templates/index.html`、`static/css/app.css`、`static/js/app.js`：前端。
- `static/images/hero.png`：ImageGen 生成的项目插画。实际交付动效为 CSS 动画，不是 GIF 视频生成。
- `static/vendor/feather.min.js`：本地图标库，MIT 许可证见同目录。
- `image_service.py`：Grsai 图片后台任务，默认模型 `gpt-image-2.6`。`IMAGE_API_KEY`、`IMAGE_BASE_URL`、`IMAGE_MODEL` 在 `.env` 配置。
- `instance/activity-images/`：按活动类型和模型缓存的生成图片与任务状态，不含日记正文，随 `instance/` 一起忽略提交。

数据库只在本机保存。点击确认复盘后，仅所选日记会由后端发送到 DeepSeek。时间线的活动类型用于 Grsai 配图，不发送日记正文；文字完成后图片在后台生成，同类活动复用本地缓存，生成或加载失败可单独重试。AI 功能需要网络和可用的 API 账户余额；其他记录功能可离线运行。AI 内容属于生活参考，不能替代医生、心理咨询师或营养师意见。

备份时先停止服务，再复制整个 `instance` 文件夹和本机 `.env`；不要将含私人日记或密钥的备份公开分享。

本地服务仅监听 `127.0.0.1`。线上部署见下文。

## Vercel 自动部署

生产地址：https://cwdiary-gray.vercel.app/ 。GitHub `main` 分支连接 Vercel 项目 `cwdiary`，推送后由 Vercel 构建前后端。

- Framework Preset：Flask；Root Directory：仓库根目录；不要设置静态网站的 Output Directory。
- `pyproject.toml` 指定 `wsgi:app`，构建时把 `static/` 复制到 `public/static/` 供 CDN 发布；首页、账号和业务 API 仍由同源 Flask 提供。
- Production 环境需要 `SECRET_KEY`（稳定随机密钥）、`TURSO_DATABASE_URL` 和 `TURSO_AUTH_TOKEN`。Turso 使用独立云数据库，不会上传本机私人数据库。Preview 应使用独立测试数据库。
- 未配置 Turso 时首页可访问，但账号/记录 API 返回503，不会将用户记录写入临时 SQLite 造成数据丢失。`/healthz` 返回当前数据库配置状态；未配置返回503。
- `DEEPSEEK_API_KEY` 及相关地址/模型变量用于文字复盘；`IMAGE_*`、`ELEVENLABS_*` 用于图片和语音。密钥只放 Vercel 后端环境变量。
- Turso 同时持久保存私有头像、活动图、音频及任务状态，`/tmp` 仅是可恢复缓存。云端图片按请求推进、音频分阶段推进，并以过期租约避免多实例同时执行同一任务；不依赖响应返回后的本地线程。轻音乐可从本机后端库同步到私有云缓存，不发布到前端静态目录。
- 云端不使用本机账号库。发布后用户需要单独注册；本机日记和账目不会自动迁移到公开部署。

### 显式导入本机数据库

`scripts/import_local_to_turso.py` 可在管理者明确要求时执行一次数据迁移。它先备份本地数据库及线上业务表，再在事务内导入账号、日记、账目、复盘和密码历史，重新映射所有归属编号。用户名与密码哈希保持不变；遇到同名但不同密码哈希的线上账号时，导入账号使用 `-local` 后缀，避免将私人记录归到别人名下。

连接凭据通过 `TURSO_DATABASE_URL` / `TURSO_AUTH_TOKEN` 环境变量，或 `--credentials-stdin` 的私有标准输入传入，不写入脚本或 Git。备份及报告保存在被忽略的 `instance/backups/`，权限仅限当前用户。相同源记录重复导入会跳过，不产生重复日记；已导入源记录发生变化时会拒绝覆盖，需另行决定合并策略。迁移脚本不会在构建、部署或应用启动时自动执行。

## 账号重复校验与声音陪伴

用户名经 NFKC 规范化、去除首尾空白并忽略大小写后，以数据库唯一索引约束；注册重复返回409，登录使用相同规范化规则。密码采用独立随机盐的 PBKDF2 哈希，不在接口返回；不同账号可以选择相同密码。改密必须验证旧密码、确认新密码，并拒绝当前密码及已记录的历史密码；既有账号从本次迁移时的密码开始建立历史记录，无法追溯迁移前未保留的旧密码。改密后其他会话失效。

复盘时间线右上角的小喇叭打开声音与计时面板：选择温暖女声/男声、1分钟至完整建议时长、日间/睡前祝福，先准备音频，再点击开始。背景音乐循环播放，配音时自动降低伴奏音量；到达项目边界切换语音，结束时播放对应祝福。可暂停/继续、静音、调节音乐音量、跳过或结束。关闭日记、离开当前视图或退出账号会停止播放。计时采用绝对经过时间，避免后台定时器节流造成累计漂移；浏览器关闭及设备休眠不保证准时播报。

- ElevenLabs 凭证仅存本地 `.env`，模型 `eleven_v4_turbo`。仅在用户点击准备声音确认后，发送屏幕上的本次活动标题与做法，不向配音服务发送日记正文、昵称或模型生成的私人总结。
- 本地音乐和配音存于 `instance/audio-library/`；三段原创器乐为每段120秒的AAC音频。本次 Eleven Music 接口返回402，因此这些伴奏由 `scripts/compose_local_music.py` 本地创作合成，并非 Eleven Music 输出。
- 女声/男声、中英文样本与日间/睡前结尾由 ElevenLabs v4 Turbo 生成并缓存。每次活动引导按所选公开活动、时长、声音和语言生成一次后复用。
- 后台准备命令：`.venv/bin/python scripts/prepare_audio_library.py`；本地器乐制作：`.venv/bin/python scripts/compose_local_music.py`（需要开发依赖numpy和macOS的afconvert）。
- 素材目录、生成提示词、库清单均不下发给浏览器；当前复盘仅按需读取所需图片和音频。音频状态与媒体接口要求登录，按用户隔离会话，可支持Range请求；没有用户端音乐库或图库列表。
- 账号迁移前备份：`instance/backups/before-guided-audio.sqlite3`。验收见 `docs/guided-audio-qa.md`。


## 离线小游戏

左栏顺序为心情足迹、我的日记、记账簿、离线小游戏、个人中心。游戏沿用第二版暖色设计，可在已登录的应用内打开：

- 记忆翻牌：12张牌、6组与个人中心相同的本地动物头像（猫、狗、兔、狐狸、熊猫、小熊），随机洗牌、错配翻回、配对锁定、完成提示及重新开始。
- 井字棋：用户先手、电脑后手；电脑优先取胜或阻挡，识别胜负和平局，可再来一局。
- 2048数字合成：方向键/WASD、滑动或按钮移动，计分、单步撤销、胜负提示和重新开始。按钮按用户草图排列，宽屏位于棋盘右下方，窄屏换到棋盘下方靠右。

逻辑与图标全部随本地页面加载，游戏本身不发网络请求、不调用AI、不上传或持久化游戏记录。所有游戏规则在浏览器本地执行；首次打开或刷新整个应用仍需启动本地服务。验证截图位于 `docs/screenshots/games-*.png`。

## 四种界面语言

登录/注册页与个人中心支持简体中文、繁體中文（中國香港）、繁體中文（中國台灣）、English。登录前选择记录在浏览器；注册时记录到账户；个人中心切换后点击保存资料，重新登录继续沿用。日期和金额格式跟随区域。日记正文、标题、昵称及手动账目不改写。复盘按所选语言生成，切换已保存语言会使旧语言复盘失效。

界面转换使用本地 `static/vendor/opencc-cn2t.js`（opencc-js 1.4.2，许可证同目录），无CDN请求；后台使用固定版本 opencc-python-reimplemented，香港采用s2hk、台湾采用s2twp。配音支持独立语言选择：简体普通话用zh、香港粤语用yue、台湾国语用zh、英语用en。台湾选项使用当地繁体字词，没有独立的台湾口音参数。

## 朗读语言同步

活动时间线的小喇叭中新增“朗读语言”，默认跟随当前界面语言，也可单独选择。配音字幕及结束祝福与所选语言一致，独立朗读选择不修改账户语言。

播放中切换会暂停旧配音、音乐和计时，准备新语言后从当前步骤及剩余时间继续；原来暂停时继续保持暂停。结束祝福播放时切换也会更换祝福语言。切换失败显示错误并停止旧音频；连续切换只接纳最后一次请求结果。不同语言、声音和模型分别缓存在本地后端，前端取得受登录保护的音频URL。

每次准备配音都先将选定活动的标题、说明交给DeepSeek改写成目标语言的自然口语，即使源语言和朗读语言相同也会处理，再交ElevenLabs生成配音；不发送日记正文，不改变活动ID、顺序、时长或原始复盘。普通话、粤语、台湾国语和英语均使用简短日常说法，保留原有提醒；开场和结束祝福也使用口语。配音与会话缓存升级为口语版本，重新准备不会复用旧书面语配音。实际查询配置的eleven_v4_turbo模型确认支持zh/yue/en，参见 [ElevenLabs模型文档](https://elevenlabs.io/docs/overview/models)。验收使用隔离数据库，未改动真实账户、日记或其当前播放页面。四种口语样例保存在 `docs/design/spoken-script-samples.json`。
